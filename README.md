# CSE 303: Abalone & Crab Age Prediction Project

## 📚 Project Overview

This is a comprehensive data science project focused on predicting the age of abalone from physical measurements, with a comparative analysis of abalone and crab age prediction models.

## 📈 Key Metrics

The project evaluates models based on:
- **R-squared (R²):** Coefficient of determination
- **RMSE:** Root Mean Squared Error
- **MAE:** Mean Absolute Error
- **Cross-validation scores:** Model generalization ability
