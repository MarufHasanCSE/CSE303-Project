🐚 Abalone Dataset

Overview

The abalone dataset contains physical measurements of abalone specimens collected from Australian waters. It is one of the most widely used datasets in machine learning for regression tasks.

File Name: abalone.csv
Total Records: 4,177
Total Features: 9
Missing Values: None
Data Type: Numeric & Categorical

Features Description

Feature Type Range/Categories Description
Sex Categorical M, F, I Male, Female, Infant
Length Numeric 0.075 - 0.815 mm Longest shell measurement
Diameter Numeric 0.055 - 0.650 mm Shell diameter perpendicular to length
Height Numeric 0.0 - 1.130 mm Height with meat in shell
Whole Weight Numeric 0.002 - 2.826 grams Whole abalone weight
Shucked Weight Numeric 0.001 - 1.488 grams Weight of meat
Viscera Weight Numeric 0.0005 - 0.760 grams Gut weight (after bleeding)
Shell Weight Numeric 0.0015 - 1.005 grams Weight of dried shell
Rings (Age) Numeric 1 - 29 Target variable: Age in years (+1.5)

🦀 Crab Dataset

Overview

The crab dataset contains morphological measurements of crabs used for age prediction and classification. This dataset provides interesting comparisons with the abalone data for species-specific analysis.

File Name: CrabAgePrediction.csv
Total Records: 3,893
Total Features: 7
Missing Values: None
Data Type: Numeric

Features Description

Feature Type Range Description
Index Numeric 1 - 3,893 Specimen identifier
Sex Categorical Male, Female Gender of the crab
Length Numeric 7.2 - 34.0 mm Carapace length
Diameter Numeric 5.8 - 29.1 mm Carapace width
Height Numeric 3.2 - 18.7 mm Body depth
Weight Numeric 0.8 - 5150 grams Total body weight
Shucked Weight Numeric 0.3 - 2485 grams Weight without shell
Age (Years) Numeric 1 - 25 Target variable: Age

⚙️ Data Processing Steps

1. Data Loading

Datasets loaded from CSV files using pandas. Initial shape verification and data type inspection performed.

2. Exploratory Analysis

Statistical summaries computed. Distribution of features analyzed. Correlation matrices generated.

3. Feature Engineering

New features created from existing ones. Categorical variables encoded. Polynomial features generated for enhanced models.

4. Data Normalization

Features scaled to zero mean and unit variance. Standard scaling applied for regression models.

5. Train-Test Split

80-20 split applied for model training and evaluation. Stratified sampling ensured balanced distributions.

6. Validation

Cross-validation performed with 5 folds. Model performance metrics calculated and compared.
